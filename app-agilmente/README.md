# 💻 App Agilmente — Protótipo de Alta Fidelidade

Aplicação web desenvolvida em **React + Vite** para a gestão e inscrições de eventos em Semanas Acadêmicas.

## 🚀 Como executar o projeto localmente

* **1. Acesse a pasta do projeto:** `cd app-agilmente`

* **2. Instale as dependências:** `npm install`

* **3. Inicie o servidor de desenvolvimento:** `npm run dev`

* **4. Acesse no navegador** o endereço local exibido no terminal (geralmente `http://localhost:5173`).
